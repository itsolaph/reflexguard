# Integer specification

`ml/features.py` is the reference; `src/reactive/ReflexGuardRC.sol` must match it operation for operation.
`test/Parity.t.sol` replays `ml/vectors.json` and compares score and packed features for every swap.

## Input

One `Swap` log per swap: `zeroForOne`, `amountIn`, `reserve0`, `reserve1` (post-swap) and `timestamp` (seconds,
taken from the event, never from the block the RC runs in). `amountOut` is ignored.

Skipped without touching state: `reserve0 == 0` or `reserve1 == 0`.

Clipping before any arithmetic: `ts <= 2^64-1`, `reserve0, reserve1 <= 2^96`, `amountIn <= reserveIn`
(`reserveIn` is the post-swap reserve of the input token).

## Derived values

| name | definition | unit |
|---|---|---|
| `rel` | `amountIn * 65536 // reserveIn` | Q16 fraction of the input-side reserve |
| `price` | `clip((reserve1 << 32) // reserve0, 1, 2^127-1)` | Q32 |
| `sign` | `+1` if `zeroForOne` else `-1` | |
| `dt` | `ts - last_ts` if the state has been used and `ts > last_ts`, else 0 | s |

## State (two storage slots)

| field | meaning | half-life |
|---|---|---|
| `priceEma` | EMA of `price`; 0 means "no swap seen" | 128 s |
| `reserveEma` | EMA of `reserve0` | 1024 s |
| `flow` | decayed signed `rel` | 32 s |
| `volume` | decayed `rel` | 32 s |
| `rate` | decayed swap count (each swap adds 65536) | 32 s |
| `timestamp` | `ts` of the last swap | |

Decay factor for half-life `2^k` seconds, in Q16: `DECAY[(dt & (2^k-1)) >> (k-5)] >> (dt >> k)`, where
`DECAY[i] = round(65536 * 2^(-i/32))`, i = 0..31. Flow, volume and rate are multiplied by the k=5 factor and
shifted right by 16. EMAs move by `((x - ema) * (65536 - factor)) >> 16`. The first swap sets both EMAs to the
current value. All right shifts are arithmetic (floor), signed divisions truncate toward zero.

## Features (Q10, 1024 = 1.0)

Computed from the decayed state before the current swap is added, unless noted.

| # | name | formula | range |
|---|---|---|---|
| 0 | size | `min(rel >> 3, 2048)` (12.5% of the reserve = 1.0) | 0..2048 |
| 1 | reversal | `clip((-sign * flow) >> 3, ±2048)`: how much recent opposite flow this swap unwinds | ±2048 |
| 2 | reserve drift | `clip((reserve0 - reserveEma) * 8192 / max(reserveEma, 1), ±2048)` | ±2048 |
| 3 | rate | `min(rate_after >> 10, 2048)` (16 decayed swaps = 1.0) | 0..2048 |
| 4 | volume | `min(volume_after >> 4, 2048)` | 0..2048 |
| 5 | price deviation | `clip((price - priceEma) * 8192 / max(priceEma, 1), ±2048)` | ±2048 |

`flow_after = flow + sign * rel`, `volume_after = volume + rel`, `rate_after = rate + 65536`.
The EMAs are updated after features 2 and 5 are computed.

Features are packed into the `Scored` event as six int16, feature 0 in the lowest 16 bits.

## MLP: 6 -> 8 ReLU -> 1

65 int16 weights, flat order: `W1[8][6]` row-major (Q8), `b1[8]` (Q10), `W2[8]` (Q8), `b2` (Q10).

```
pre_j  = ((sum_i W1[j][i] * f[i]) >> 8) + b1[j]      Q10
h_j    = clip(pre_j, 0, 16383)
logit  = ((sum_j W2[j] * h_j) >> 8) + b2             Q10, clipped to ±8192
```

Storage: weight `n` sits at bits `16 * (n % 16)` of word `n // 16`; five `uint256` immutables.

## Score

`z = logit + 8192`, `i = z >> 9`, `frac = z & 511`. If `i >= 32`, the score is `SIGMOID[32]`; otherwise
`SIGMOID[i] + (((SIGMOID[i+1] - SIGMOID[i]) * frac) >> 9)`, where
`SIGMOID[i] = round(10000 / (1 + exp(-(512 i - 8192) / 1024)))`, i = 0..32. Range 0..10000.

The tables are generated by `ml/gen_tables.py` into `src/reactive/ReflexTables.sol`.

## Halt policy

`score >= threshold` requests a callback unless one was requested less than 60 s (event time) ago and no
`Resumed` has been seen since. `Resumed` clears the state and the halted marker.
